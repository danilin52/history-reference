# 📜 Исторический справочник

Android-приложение — карманный справочник по ключевым датам и личностям мировой и отечественной истории. Помогает быстро найти событие, узнать, кто в нём участвовал, и каждый день напоминает о важной дате.

## ✨ Возможности

- **Лента событий** — хронологический список с датой, категорией, местом и важностью (1–10).
- **Поиск по личности** — по имени или роду деятельности.
- **Детальный просмотр** — описание события и связанные личности; биография человека и его события.
- **Полный CRUD** — добавление, просмотр, изменение и удаление событий, личностей и связей между ними.
- **Настройки** — имя пользователя, тема и уведомления сохраняются через SharedPreferences.
- **Сетевой слой** — подготовлен клиент Wikipedia REST API и загрузка изображений через Coil.
- **Уведомления** — ежедневное «В этот день…» через WorkManager.
- **Анимация** — карточка события появляется с вращением.

## 🧩 Модель данных

| Сущность | Поля |
|---|---|
| `HistoricalEvent` | дата, название, описание, категория, место, важность, URL изображения |
| `Person` | имя, год рождения, год смерти, биография, URL портрета, род деятельности |
| `EventPerson` | событие, личность, роль (участник / свидетель / инициатор) |

## 🛠 Технологии

Kotlin · Jetpack Compose (Material 3) · Room (KSP) · SharedPreferences · Retrofit + Gson · Coil · WorkManager · Navigation Compose

Списки реализованы через `LazyColumn` — современный аналог `RecyclerView` для интерфейса на Jetpack Compose.

## 📦 Структура проекта

- `data/` — сущности, DAO, база данных, репозиторий, демо-данные, Retrofit
- `notifications/` — ежедневное уведомление «В этот день…»
- `preferences/` — настройки пользователя на SharedPreferences
- `ui/components/` — анимированная карточка события
- `ui/events/` — список событий
- `ui/persons/` — поиск по личности
- `ui/detail/` — детальные экраны
- `ui/nav/` — навигация
- `ui/settings/` — настройки пользователя
- `ui/theme/` — тема
- `HistoryApp.kt` — инициализация приложения
- `MainActivity.kt` — точка входа

## 🧪 Лабораторные работы

### ЛР №1 — пользовательский интерфейс и навигация

Главные разделы объединены нижней панелью `NavigationBar`. Навигация построена на Navigation Compose, состояние вкладок сохраняется, а формы и детальные экраны открываются отдельными маршрутами.

### ЛР №2 — работа с локальными данными

Для `HistoricalEvent`, `Person` и `EventPerson` реализованы Entity, DAO и база Room. Добавление, чтение, изменение и удаление доступны из интерфейса. Пользовательские настройки сохраняются в SharedPreferences.

## 🚀 Сборка

1. Откройте папку проекта в Android Studio (Giraffe+ / Ladybug).
2. Дождитесь синхронизации Gradle (обёртка подтянется автоматически).
3. Запустите `app` на эмуляторе или устройстве (minSdk 26).

### Полное описание

**«Исторический справочник» — вся история в кармане.**

Готовитесь к ЕГЭ по истории или просто любите узнавать новое? Это приложение для вас! Важные даты, судьбы великих людей и события, изменившие мир, собраны в удобной ленте с поиском.

- 📅 **События по датам** — от Невской битвы до полёта Гагарина. Каждое событие содержит категорию, место и оценку важности.
- 🔍 **Поиск по личности** — найдите человека по имени или роду деятельности и узнайте, что он совершил.
- 🖼 **Портреты и описания** — приложение подготовлено к загрузке дополнительных материалов из сети.
- 🔔 **«В этот день…»** — ежедневное напоминание об историческом событии.
- 🎨 **Плавные анимации** — карточки событий появляются с вращением.

Приложение подойдёт школьникам и студентам, готовящимся к экзаменам, историкам, преподавателям и всем, кто хочет расширить кругозор.

Базовые данные доступны без подключения к интернету. В приложении нет рекламы.
