# 📜 Исторический справочник

Android-приложение — карманный справочник по ключевым датам и личностям мировой и отечественной истории. Помогает быстро найти событие, узнать, кто в нём участвовал, и каждый день напоминает о важной дате.

## ✨ Возможности

- **Лента событий** — хронологический список с датой, категорией, местом и важностью (1–10).
- **Поиск по личности** — по имени или роду деятельности.
- **Детальный просмотр** — описание события и связанные личности; биография человека и его события.
- **Сеть** — подгрузка описаний и портретов (Wikipedia REST API + Coil).
- **Уведомления** — ежедневное «В этот день…» через WorkManager.
- **Анимация** — карточка события появляется с вращением.

## 🧩 Модель данных

| Сущность | Поля |
|---|---|
| `HistoricalEvent` | дата, название, описание, категория, место, важность, URL изображения |
| `Person` | имя, год рождения, год смерти, биография, URL портрета, род деятельности |
| `EventPerson` | событие, личность, роль (участник / свидетель / инициатор) |

## 🛠 Технологии

Kotlin · Jetpack Compose (Material 3) · Room (KSP) · Retrofit + Gson · Coil · WorkManager · Navigation Compose

## 📦 Структура проекта

- `data/` — сущности, DAO, база данных, репозиторий, демо-данные, Retrofit
- `notifications/` — ежедневное уведомление «В этот день…»
- `ui/components/` — анимированная карточка события
- `ui/events/` — список событий
- `ui/persons/` — поиск по личности
- `ui/detail/` — детальные экраны
- `ui/nav/` — навигация
- `ui/theme/` — тема
- `HistoryApp.kt` — инициализация приложения
- `MainActivity.kt` — точка входа

## 🚀 Сборка

1. Откройте папку проекта в Android Studio (Giraffe+ / Ladybug).
2. Дождитесь синхронизации Gradle (обёртка подтянется автоматически).
3. Запустите `app` на эмуляторе или устройстве (minSdk 26).
